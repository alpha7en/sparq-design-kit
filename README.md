# SPARQ Studio — плагин Claude Desktop для дизайна в стиле SPARQ

Claude сам собирает в Figma **презентации** (1920×1080) и **карусели карточек для Telegram** (1080²) в стиле SPARQ, проверяет их на ошибки вёрстки и текста, читает ваши комментарии в Figma и исправляет. Дизайн-система — токены, стили, иконки, компоненты карточек, движок слайдов, генераторы графиков — запечатана внутри плагина: новый файл Figma готовится одной командой.

## Установка (≈ 10 минут, один раз на компьютер)

**Нужно заранее**
- **Claude Desktop**, вкладка **Code** (плагины работают там).
- **Node.js 18+**: nodejs.org → кнопка LTS → установить.
- **Figma Desktop** (не браузер): figma.com/downloads.

**Шаг 1. Плагин.** В Claude Desktop → Code напишите Claude:
> Установи плагин SPARQ Studio: выполни `claude plugin marketplace add alpha7en/sparq-design-kit`, затем `claude plugin install sparq-studio@sparq`.

Если Claude ответит, что команды `claude` нет, — попросите его сначала выполнить `curl -fsSL https://claude.ai/install.sh | bash` (установка Claude Code), затем повторить. То же самое можно сделать в Терминале. Затем **полностью перезапустите Claude Desktop** (⌘Q и открыть заново).

**Шаг 2. Мост в Figma.** Напишите Claude: **«/sparq-studio:setup»** — он проведёт по шагам. Суть: Figma Desktop → **Plugins → Development → Import plugin from manifest…** → файл `~/.sparq-studio/bridge/manifest.json` (в окне выбора файла нажмите ⌘⇧G и вставьте путь `~/.sparq-studio/bridge`). Плагин называется **SPARQ Studio Bridge**.

**Шаг 3. Доступ к комментариям Figma** (нужен, чтобы Claude читал ваши замечания — см. «Правки через комментарии» ниже). Figma → значок профиля → **Settings → Security → Personal access tokens → Generate new token**; права: *File content — Read*, *Comments — Read*. Скопируйте токен, создайте файл `~/.sparq-studio/figma-token` (например, в TextEdit: Формат → Сделать простым текстом, сохранить под этим именем) и вставьте туда токен одной строкой. В чат токен не вставлять.

**Проверка:** напишите «/sparq-studio:status» — Claude скажет, подключён ли мост и какие файлы Figma открыты.

**Обновление:** «выполни `claude plugin marketplace update sparq` и `claude plugin update sparq-studio@sparq`» → перезапуск Claude Desktop.

## Как работать

- Открыть файл в Figma Desktop → **Plugins → Development → SPARQ Studio Bridge** (в каждом файле, с которым работаете).
- В Claude:
  - `/sparq-studio:status` — что открыто и что установлено;
  - `/sparq-studio:deck путь/к/ТЗ.md` — собрать презентацию;
  - `/sparq-studio:cards путь/к/посту.md` — собрать карусель;
  - `/sparq-studio:comments` — прочитать ваши комментарии в Figma и исправить;
  - `/sparq-studio:review` — проверка свежим взглядом и вычитка;
  - `/sparq-studio:export pdf` — выгрузка.
- Можно и без команд, обычными словами: «сделай презентацию по этому ТЗ», «поправь слайд 6», «вычитай тексты».

## Правки через комментарии Figma

Самый удобный способ править — не описывать ошибки в чате, а оставлять их прямо на макете.

1. В Figma включите инструмент **Comment** (значок облачка на верхней панели или клавиша **C**).
2. Кликните в любое место — на слово, график, иконку, пустоту, край слайда — и напишите, что не так: «слишком ярко», «перенеси вправо», «тут ошибка в цифре», «сделай так на всех слайдах». Комментариев может быть сколько угодно, на разных слайдах и карточках.
3. Напишите Claude: **«/sparq-studio:comments»** или просто «посмотри мои комментарии».

Claude сам получит все новые комментарии файла, поймёт, к какому слайду/карточке и к какому тексту рядом относится каждый, покажет короткий список «где · что просите · как исправлю», исправит, проверит скриншотами и отчитается. Замечание вида «везде» или повторяющееся в нескольких местах он применяет ко всей работе, а не к одной точке. Уже решённые (Resolve) комментарии не трогает. Если что-то в комментарии неоднозначно — переспросит.

Примеры: в файле Figma **SPARQ.2 framework** страницы «SPARQ · система 1:1 (всё здесь)» (карточки) и «SPARQ · презентации 16:9» (каталог блоков и живая презентация).

## Что внутри

| часть | где | что |
|---|---|---|
| плагин | `plugins/sparq-studio/` | скиллы (старт, презентации, карточки, редактура, уроки правок), команды, три агента-проверяющих, хук старта |
| MCP-сервер | `plugins/sparq-studio/server/` | форк [figma-console-mcp](https://github.com/southleft/figma-console-mcp) (MIT) + инструменты `sparq_*`, собран в один файл |
| мост для Figma | `plugins/sparq-studio/server/figma-desktop-bridge/` | плагин Figma «SPARQ Studio Bridge» |
| дизайн-система | `plugins/sparq-studio/design/` | токены, иконки, библиотека 292 компонентов карточек, рантайм (движок слайдов, генераторы, проверки) |
| исходники | `mcp/`, `design/`, `tools/` | для разработчиков: `docs/ARCHITECTURE.md`, `docs/MAINTAINING.md`, состояние по ТЗ — `docs/STATUS.md` |
