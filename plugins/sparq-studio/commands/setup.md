Загрузи скилл sparq-studio и проведи настройку по `references/setup.md` («Сценарий первой настройки»).

Сначала тихо выполни `node -v` и `sparq_status`. Затем **первым сообщением** покажи пользователю этот план (дословно, подставив статусы ✅/⬜ по факту проверки), и сразу начни с первого незавершённого шага:

> Настройка в 4 шага, ~5 минут:
> 1. Node.js — программа, на которой работает мост (проверила/проверил автоматически)
> 2. Figma Desktop — приложение (не сайт)
> 3. Плагин-мост для Figma «SPARQ Studio Bridge» — я открою вам папку с его файлом, останется один раз импортировать его в Figma
> 4. Подключение вашего рабочего файла Figma и его подготовка

Правила: один шаг за сообщение; в каждом шаге называй точные пункты меню; слово «файл» всегда уточняй («файл плагина manifest.json» или «ваш файл Figma»); не проси открыть рабочий файл Figma, пока мост не импортирован; шаги, уже выполненные по `sparq_status`, пропускай. Назначение рабочего файла: $ARGUMENTS (если пусто — спроси на шаге 4).
