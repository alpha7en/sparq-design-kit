# Проверка слайдов: что ищем и как исправляем

Порядок: ответ `sparq_slides` (issues + lint) → скриншот 0.5–0.8 → этот чек-лист → правка спецификации → пересборка. Слайд сдан, только когда issues пусты (кроме осознанных) и скриншот просмотрен глазами. Скриншот без картинки (ошибка, лимит) = не проверено.

## Аккуратность (первична)
- Нет наездов, касаний линий, выхода за край, переноса внутри слова. Перенос «слово-/слово» по дефису допустим.
- Зазор между блоками ≥ их внутреннего отступа («внутреннее < внешнего»); подпись ближе к своему блоку, чем к соседнему.
- Колонки ряда начинаются и заканчиваются на одной высоте; одинаковые элементы — одинаковые отступы.
- Пустота снизу > 170 px на контентном слайде — брак: `fill:true`, крупнее отступы, визуальный блок.
- Текст ≥ 28 px (14 pt) везде, кроме сносок и служебных подписей. Не влезает — сокращаем текст, не кегль.
- В блоке ≤ 5 пунктов, пункт ≤ 2 строк.

## Стиль SPARQ
- Тёмная основа, 3–6 светлых слайдов на колоду; красный — только акцент (линия, точка, одно число, полоса), без больших красных площадей и ярко-красных чисел подряд.
- Цифры-герои белые (на светлом — чёрные или `deep`); красное число — максимум одно на слайд.
- Инверсная плашка (`card inverse`) — главный блок, ≤ 1 на слайд, ≤ 4 на колоду.
- Иконки одного набора и одного цвета на слайде; без эмодзи, стока, 3D.
- Индексы `|n⟩` вместо маркеров там, где нет иконок; моноширинный шрифт — только для служебного.
- Декор (`field`) — только в реально свободной зоне, не под текстом, тише содержания.

## Смысл для читателя «с холода»
- Перед слайдом сформулировать: «после слайда читатель знает …». Если фраза не складывается — слайд не нужен или перегружен.
- Термин впервые появляется вместе с объяснением; порядок слайдов ведёт от проблемы к решению.
- Цифры на слайде = цифры в источнике/ТЗ; источник в `foot`, не в тексте.
- Перед сдачей — вычитка (скилл sparq-editor) по каждой фразе.

## Классы ошибок, которые пропускали (из комментариев заказчика)
1. Правка «везде» сделана в одном месте → после правки искать то же по всем слайдам (`sparq_audit` без ключей + поиск текста).
2. Стыки декора с текстом и логотипами не проверялись → смотреть детали кадром 2× (`figma_capture_screenshot scale:1` на узел).
3. Плашки по умолчанию вместо иерархии кеглем и позицией → плашка только когда группирует.
4. Пересборка затёрла ручные правки пользователя → `sparq_slides` сам останавливается (`manualEdits`); перенести правки в спецификацию.
5. Голос: «вы», «кому?», ИИ-штампы, самолюбование и пустые ярлыки → `sparq_text_lint` + ручная вычитка.
6. Слишком ярко/глаз режет (красные числа, светлые плашки на каждом слайде) → правила стиля выше.
7. Мало знаков → каждому однородному перечню иконки, цифрам — инфографику.

## Экспорт
`sparq_export {format:"pdf"}` — проверить размер (часто лимит 2 МБ): тяжёлые — фото и скриншоты (JPEG ≤ 300 КБ), размытия и зерно.
