# SPARQ · карусели 1080²

Карусель собирается **только из системы**: виды карточек, фоны, генераторы графиков, иконки. Ты выбираешь вид и данные — инструмент `sparq_cards` рисует, подбирает фон, проверяет вёрстку. Хорошая карусель — это правильный выбор видов, а не украшения.

## Что считается готовым
1. Каждая карточка — одна мысль; текст автора, правки только редакторские (скилл `sparq-editor`).
2. Вид карточки соответствует объёму и типу содержания (таблица ниже). Пустота — признак не того вида, а не повод что-то добавить.
3. Фоны тихие: линии и кольца; никаких пятен, свечений и ярких точек. Красный — неоновая дуга обложки, одно число-герой, акцентный столбец графика, красная финальная карточка.
4. Ритм: обложка → суть → данные → финал; одна светлая карточка; красная — не больше одной, кроме финала; соседние карточки не повторяют приём.
5. Проверка инструмента чистая (`lint`), `notes` разобраны, скриншот всего ряда просмотрен.

## Порядок
1. `sparq_status`. Нужен дизайн-файл (не Slides) с набором `cards`. Если `sparq_setup_file` сообщает «outdated» — повторить с `replaceLibrary:true`.
2. Раскладка: таблица `№ · мысль · вид · графика/иконки` — показать пользователю одним сообщением и сразу собирать.
3. Сборка: `sparq_cards {slug, cards:[…]}` по 3 карточки за вызов. Фон не указывать (кроме обложки).
4. Разбор ответа: каждая `notes` и `lint` → действие по таблице «Сигналы». Пересобрать на той же странице.
5. Скриншот ряда (`figma_capture_screenshot`, scale 0.5), затем вычитка текстов, затем агент `sparq-critic`.
6. Отчёт: что собрано, что спорно, какие факты проверить.

## Выбор вида
| содержание | вид | слов |
|---|---|---|
| обложка | `typo` + обложка по теме (см. `references/catalog.md`); `person`, `duo`, `photo-*` — с фото | 1–3 в заголовке |
| одно число решает | `hero` (`number` + пояснение) | ≤ 30 |
| цитата | `quote` | ≤ 45 |
| короткий тезис | `text-s` | ≤ 40 |
| абзац | `text-m` | 41–85 |
| длинный абзац | `text-l` | 86–150 |
| 3–4 однородных пункта | `list` + `items` с иконками | ≤ 60 |
| две модели рядом | `two-sections` | 2 × ≤ 35 |
| данные | `graphic-M/L/XL/SW/SN` + `chart` (`references/charts.md`) | ≤ 50 / 35 / 9 |
| кейс | `case` (`kicker`) | ≤ 70 |
| вывод «кому важно» | `bubble` | ≤ 41 |
| финал | `final-tail` (красная) или `final-figures` | ≤ 60 |
Текст не помещается — следующий вид или вторая карточка; кегль не уменьшать.

## Спецификация
```json
{"kind":"list","props":{"title":"где применяют","counter":"|3/5⟩","text":"Кудиты полезны в четырёх задачах:"},
 "items":[{"icon":"chip","title":"компактные процессоры","note":"меньше элементов"}]}
{"kind":"graphic-L","props":{"title":"госбюджеты","counter":"|2/6⟩","text":"…**$15,3 млрд**…"},
 "chart":{"type":"barH","size":"L","data":{"data":[{"label":"Китай","value":15.3,"accent":1}],"pre":"$"}}}
{"kind":"typo","bg":"cover-sphere","rubric":"explain","props":{"title":"что такое\nкудит","series":"|кудиты 1⟩"}}
```
`**жирное**` в тексте становится выделением. Два слоя с одним именем: `texts:{"text#2":"…"}`. Полный перечень полей — `references/catalog.md`.

## Сигналы инструмента
| сигнал | действие |
|---|---|
| `notes`: «пустой низ» | взять вид поменьше (`text-s`, `hero`, `quote`) или добавить график из каталога, если есть данные |
| `notes`: «слов N, норма вида …» | сменить вид по таблице |
| `notes`: «фон … заменён» | ничего, так и задумано |
| `notes`: «заголовок уменьшен» | ничего; если заголовок длинный — сократить до 1–3 слов |
| `lint`: перенос внутри слова, край, кегль | сократить текст или сменить вид |
| `lint`: декор под контентом | не указывать фон вручную (автоподбор) |

## Нельзя
- Рисовать или двигать элементы вручную (`sparq_run`), если пользователь прямо не попросил нарисовать что-то новое. Комментарии исправляются выбором из каталога.
- Добавлять бейджи, плашки, подписи, иконки, декор ради заполнения места.
- Ставить фон вручную на карточки кроме обложки; ставить пятна, свечения, яркие точки.
- Придумывать графики вне каталога и данные вне текста.
- Ставить источники и @-ники на карточки.
- Создавать новые страницы-версии вместо пересборки.

Комментарии заказчика — по протоколу в `sparq-studio/references/workflow.md`: текст → правка, композиция → другой вид/фон/график из каталога, дефект системы → сообщить, не латать.

## Ресурсы
- `references/catalog.md` — виды карточек, обложки и фоны, иконки, шаблоны каруселей, поля спецификации.
- `references/charts.md` — нужна ли графика и какая; форматы данных генераторов.
- `examples/carousel-templates.jsonl` — 9 готовых каруселей (читать точечно по нужному шаблону).
