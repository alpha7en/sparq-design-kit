# Инфографика карточек: когда и какая

## 0. Нужна ли графика
Да — только если на картинке видно то, чего не прочесть в тексте за то же время: порядок величин/разрыв, сравнение 3+ объектов, доли целого, динамика (≥ 3 точек), связи/поток/последовательность, позиции на двух осях.
Нет — если 1–2 числа (ключевая цифра или жирное число в тексте), мысль концептуальная, картинка повторит фразу, данных нет (тогда иконка/фон, не фальш-диаграмма).

## 1. Вопрос → форма (генератор `chart.type`)
| вопрос | данные | форма | размеры |
|---|---|---|---|
| кто больше, рейтинг | 3–12 объектов | barH | M (≤5), L (6–12), SW |
| сравнить немного с короткими именами | 2–6 | barV | M, L |
| во сколько раз разрыв | 2 числа, ≥ 5× | scale (+«×N») или hero | M |
| из чего состоит целое | 2–6 частей = 100 % | stack; waffle для «N из 100»; donut только 2–4 доли | M, L, SW |
| иерархия долей | 4–10 блоков | treemap (площадь ∝ значению) | L, XL |
| откуда куда идут деньги | 2–4 → 3–6 | sankey | XL, L |
| как менялось | ≥ 4 точек | line (1–3 серии, area для объёма) | L, XL, M |
| когда что наступит | события | timeline (гор. XL/L, верт. SW/SN) | |
| отсев по этапам | 3–5 этапов | funnel | M, L |
| уровни / стек | 3–5 уровней | pyramid | L, XL |
| схема / процесс | 3–8 блоков | flow, chain | L, XL |
| экосистема вокруг центра | центр + 3–8 | hub | L, XL |
| классификация по двум осям | 4–15 объектов | matrix | XL |
| сколько раз повторяется одно и то же | 8–40 одинаковых элементов, один выделен | strip | M, L |
| «столько же, но иначе» (два множителя) | 2–4 прямоугольника ширина×высота, равная площадь | areas | M, L |
| как устроен цикл / последовательность из 3–5 шагов | шаги с номерами, замыкание в круг | steps (loop) | L, XL |
| лучшее достигнутое во времени и порог | ≥ 3 точки, шкала от нуля, пунктир порога | stepLine | L, XL |
| было → стало в долях | 2–5 строк, закрашена оставшаяся доля | reduction | M, L |

## 2. Честность (всегда)
Одна ось Y; бары от нуля (огромный разрыв — scale с «×N» или лог-шкала с пометкой); площадь ∝ значению (проверять расчётом); неизвестное не рисовать как известное (выцветающий хвост + подпись); один акцент (red), остальное белый → frost-300 → frost-500; подписи прямо у элементов; текст в графике ≥ 28 px; числа в графике = в тексте = в источнике; 2–4 подписанных числа на мысль; без 3D, теней, неона и градиентов на данных (в новых формах неона нет; в `barH`/`barV` акцентный столбец светится — для данных лучше отключать `O.fx`). Красный текст мельче 44 px — яркий (#FF2A2A); на `strip/areas/steps/stepLine/reduction` это сделано по умолчанию.

## 3. Размер
Слоты: XL 936×664 · L 936×440 · M 936×288 · SW 456×760 · SN 296×760. Сложность ≥ 7 элементов → XL/L/SW; 2–6 → M/SN/SW. Текста ≤ 9 слов → XL; ≤ 35 → L/SW; ≤ 50 → M/SN; больше — перенос текста на соседнюю карточку, а не уменьшение графика.

## 4. Генераторы и данные
| type | data | размеры |
|---|---|---|
| barH | data[{label,value,accent?}], pre, suf | XL L M SW |
| barV | data[…], pre, suf | XL L M |
| stack | parts[{label,value,accent?}], suf | L M |
| line | x[], series[{name,values[],accent?}], pre, area, first | XL L M SW |
| donut | data[{label,value,accent?}], center{value,label}, suf | L M SW |
| timeline | events[{date,label,t?,accent?}] | XL L · SW SN |
| scale | a{value,text,label}, b{…}, ratioText? | L M |
| sankey | src[{n,v,accent?}], dst[{n,v}], flows[[i,j,v]] | XL L |
| pyramid | tiers[{n,t,cs,accent?}] | XL L |
| funnel | stages[{v,label,accent?}] | L M |
| waffle | value (%), label | L M SW |
| treemap | items[{v,label,accent?}] | XL L SW |
| flow | inputs[{a,b}], output{a,b}, caption | L M |
| chain | cols[{name,accent?,steps[{a,b,ok}]}] | XL |
| hub | center{a,b}, nodes[{a,b}] | XL L |
| matrix | xl[2], yl[2], clusters[{qx,qy,big,rest,accent?}] | XL |
| strip | count, accent[индексы], label, cols? | M L |
| areas | items[{label,w,h,note?,accent?}] (площадь = w×h в общем масштабе) | M L |
| steps | items[{text,accent?}] (3–5), loop (стрелка возврата) | L XL |
| stepLine | points[{t,v,label?,accent?,below?}], threshold{value,label}, axis[{t,label}], max? | L XL |
| reduction | rows[{label,from,to,accent?,conditional?,cutText?}] (conditional — пунктир «условно») | M L |
Пример: `"chart":{"type":"barH","size":"L","data":{"data":[{"label":"Китай","value":15.3,"accent":1},{"label":"Япония","value":9.2}],"pre":"$"}}`. Генератор возвращает `issues` — не пусто → другой размер/форма.

## 5. Перед вставкой
Ответ «что видно, чего нет в тексте» есть; форма по таблице; масштаб честный; числа сверены; один акцент; подписи ≥ 28 px; ничего не обрезано; скриншот 1080 и ~390 px просмотрен.

## 6. Рецепты связок (из практики; не клетка)
- **Один результат, два прочтения** — `areas` (равные площади разной постановки) или `reduction` (полоса «было→стало» с пунктиром «условно»); показывает разницу, которую в тексте приходится объяснять абзацем.
- **Сколько раз повторяется блок** — `strip` с одной красной ячейкой: «28 повторов» читается образом без слов.
- **Цикл улучшения** — `steps` с `loop:true`; ровно 3–5 шагов, глагол в начале, красный — шаг-итог.
- **Гонка на открытом конкурсе** — `stepLine` с пунктиром порога и подписью «момент прохода».
- Для лога-шкал с двумя панелями в одном масштабе, цитаты-героя и т. п. отдельного генератора пока нет — рисуют режимом C; если схема понадобилась второй раз, оформить генератором.
