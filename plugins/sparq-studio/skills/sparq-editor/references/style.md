# Стилевой гид SPARQ (расширенный)

## Белый список конструкций
- Жёсткое противопоставление через тире по фактам: «…метрика присутствия, а не взломостойкости».
- Точная привязка в первой фразе: «В 2022, на четвёртом раунде отбора NIST…», «В отчёте Citi (февраль 2026)…».
- Ведомство/источник в скобках сразу за сущностью: «Германия (BSI)», «США · военное (NSS)», «(июнь 2026)».
- Мультипликаторы и порядки: «в 5–7 раз больше», «на порядок».
- Стрелочные цепочки: «алгоритм (FIPS 203) → валидация (NIST CAVP) → сертификация».

## Чёрный список (как переписать)
| нельзя | почему | как |
|---|---|---|
| «В современном мире / в цифровую эпоху» | штамп | начать с факта, года, субъекта |
| «Стоит отметить / важно понимать» | пустой разгон | удалить, начать с мысли |
| «Открывают невероятные перспективы» | маркетинговый пафос | дать оценку рынка с источником |
| «Палка о двух концах» | псевдофилософия | назвать конкретный конфликт |
| «Эксперты сходятся / время покажет» | хеджирование без источника | назвать исследование и цифру |
| «Таким образом / подводя итог» | школьное резюме | сразу вывод сменой оптики |
| тройные списки ради ритма | искусственность | оставить доказанный пример |
| «хоронят», «золотые люстры» | запрещено автором | — |

## Полужирный
Всегда: числа и суммы, сроки взлома/прецеденты, названия алгоритмов и программ, аббревиатуры регуляторов и стандартов, термины-парадоксы. Никогда: глаголы и связки, целые предложения (> 5–6 слов подряд).

## Финальный блок / вывод
Не пересказ: смена масштаба (мотивы участников, институциональная логика), 2 абзаца, 80–110 слов, без графики.

## Telegram-анонс
Хук (парадокс/контраст цифр, 1–3 строки) → переходная фраза → 2–3 «🔴» вопроса без спойлера → «прошлые части» со ссылками → рубрика и теги (#sparqexplain и т. п.). 60–120 слов.

## Объёмы карточек (эмпирика 30 опубликованных)
Обложка 1–3 слова · инфографика 20–60 · вход/каталог 50–80 · гибрид 80–115 · глубокий кейс 110–135 · финал 80–110. Текст ≤ 40–45 % площади карточки.

## Аналитический отчёт (профиль report)
Голос аналитического отчёта: слегка академично, ясно с 1–2 прочтения, без «вы/мы» и самолюбования; общий вывод — отправная точка, ценность — в кейсах и схемах; не придумывать «оценки по аналогии», чтобы заполнить шаблон; формулировки о доказанности мягкие и точные («есть наработки, но на ранней стадии»), не «не доказано»; цифры для компании-заказчика не выдумывать — только в кейсах и фактах рынка.
