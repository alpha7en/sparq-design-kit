# Установка и подключение (вести пользователя по шагам)

Говорить простыми словами, по одному шагу, ждать «готово». Не просить пользователя запускать команды в терминале, если можно обойтись.

## 0. Что нужно один раз
1. **Claude Desktop** с плагином SPARQ Studio (уже стоит, раз этот текст читается).
2. **Node.js 18+** — нужен встроенному серверу. Проверка: Claude может выполнить `node -v`. Нет — предложить установить с nodejs.org (LTS) и перезапустить Claude Desktop.
3. **Figma Desktop** (не браузер): figma.com/downloads. Шрифты Unbounded, Onest, JetBrains Mono — встроены в Figma (Google Fonts), ставить не нужно.

## 1. Мост в Figma (один раз на компьютер)
1. Узнать путь к манифесту: он в ответе `sparq_status` (поле `manifest`), обычно `~/.sparq-studio/bridge/manifest.json` (папка создаётся при первом старте сервера).
2. В Figma Desktop: меню **Plugins → Development → Import plugin from manifest…** → выбрать этот `manifest.json`.
3. Плагин называется **SPARQ Studio Bridge**.

## 2. Каждый раз
1. Открыть нужный файл в Figma Desktop.
2. **Plugins → Development → SPARQ Studio Bridge** → окно плагина можно свернуть, не закрывать.
3. Повторить в каждом файле, с которым работаем (каждый файл — своё подключение).
4. Claude: `sparq_status` — файл должен появиться в списке.

## 3. Токен Figma (только для чтения комментариев)
Figma → Settings → Security → **Personal access tokens** → создать (права: File content — read, Comments — read). Сохранить токен в файл `~/.sparq-studio/figma-token` (одна строка). Claude не должен видеть или печатать токен — пользователь создаёт файл сам (например, через Finder/TextEdit).

## Частые проблемы
| симптом | что сделать |
|---|---|
| `bridge: not connected` | открыт ли плагин в файле; Figma Desktop, не браузер; перезапустить плагин |
| файл не в списке | плагин запущен в другом файле — запустить и в этом |
| работа ушла «не в тот файл» | `sparq_use_file {fileKey}` закрепляет цель |
| «kit is not installed» | `sparq_setup_file` для нужного набора |
| таймаут 30 с | собирать меньше слайдов/карточек за вызов; первый запуск грузит шрифты дольше |
| в Figma был другой figma-console MCP | не мешает: мосты делят порты 9223–9232; если путаница — закрыть старый плагин Desktop Bridge |
| после обновления плагина странности | `sparq_setup_file` ещё раз (обновит токены/стили/генераторы) |
