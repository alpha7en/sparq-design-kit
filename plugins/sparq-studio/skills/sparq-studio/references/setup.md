# Установка и подключение (вести пользователя по шагам)

Говорить простыми словами, по одному шагу, ждать «готово». Не просить пользователя запускать команды в терминале, если можно обойтись.

## Сценарий первой настройки (`/sparq-studio:setup`)
Перед первым сообщением тихо выполнить `node -v` и `sparq_status`. Если мост уже `connected` и нужный файл в списке — сразу шаг 5.

**Шаг 1 · Node.js.** `node -v` ≥ 18 — сказать «Node есть» и идти дальше. Нет — «Установите Node.js: nodejs.org → LTS, затем полностью перезапустите Claude Desktop (⌘Q)». Ждать.

**Шаг 2 · Figma Desktop.** «Нужна Figma Desktop (приложение, не браузер): figma.com/downloads. Установлена?» Ждать.

**Шаг 3 · Мост в Figma (один раз на компьютер).** Выполнить `open ~/.sparq-studio/bridge` (откроет папку с мостом в Finder; путь также в `sparq_status` → `manifest`). Сообщение пользователю:
> 1. В Figma Desktop откройте любой файл (или создайте новый: Drafts → New design file) — меню плагинов доступно только внутри файла.
> 2. Меню Figma (логотип слева вверху) → **Plugins → Development → Import plugin from manifest…**
> 3. В окне выбора нажмите ⌘⇧G, вставьте `~/.sparq-studio/bridge` → Enter → выберите **manifest.json** → Open.
> Плагин «SPARQ Studio Bridge» появится в Plugins → Development. Если он там уже есть — этот шаг пропустите.
Ждать.

**Шаг 4 · Подключение файла (каждый раз, в каждом файле).**
> Откройте файл, с которым будем работать → **Plugins → Development → SPARQ Studio Bridge**. Окно плагина можно свернуть, но не закрывать.
Затем `sparq_status`: файл в списке — назвать его и идти дальше. Нет — см. «Частые проблемы».

**Шаг 5 · Подготовка файла.** Спросить, для чего файл (презентация / карточки), если не сказано. Презентация → `sparq_setup_file {kit:"deck"}` (секунды). Карточки → только обычный дизайн-файл (не Slides), предупредить «1–2 минуты» → `sparq_setup_file {kit:"cards"}`.

**Шаг 6 · Комментарии (по желанию).** Объяснить зачем (Claude читает замечания, оставленные инструментом Comment прямо на макете) и как создать токен — раздел 3 ниже. Сам токен в чат не просить.

**Итог одной фразой:** что готово и с чего начать («пришлите ТЗ — соберу презентацию»).

## Справка по шагам
- Мост: файлы лежат в `~/.sparq-studio/bridge` (создаётся при первом старте сервера); имя плагина в Figma — **SPARQ Studio Bridge**.
- Каждый открытый файл Figma — отдельное подключение: плагин запускается в каждом файле, с которым работаем.
- Шрифты Unbounded, Onest, JetBrains Mono встроены в Figma, ставить не нужно.

## 3. Токен Figma (только для чтения комментариев)
Figma → значок профиля → Settings → Security → **Personal access tokens** → Generate new token (права: File content — Read, Comments — Read). Пользователь сам сохраняет токен одной строкой в файл `~/.sparq-studio/figma-token` (TextEdit → Формат → Сделать простым текстом). Claude не видит и не печатает токен.

## Частые проблемы
| симптом | что сделать |
|---|---|
| `bridge: not connected` | открыт ли плагин в файле; Figma Desktop, не браузер; перезапустить плагин |
| файл не в списке | плагин запущен в другом файле — запустить и в этом |
| работа ушла «не в тот файл» | `sparq_use_file {fileKey}` закрепляет цель |
| «kit is not installed» | `sparq_setup_file` для нужного набора |
| таймаут 30 с | собирать меньше слайдов/карточек за вызов; первый запуск грузит шрифты дольше |
| в Figma был другой figma-console MCP | не мешает: мосты делят порты 9223–9232; если путаница — закрыть старый плагин Desktop Bridge |
| после обновления плагина странности | `sparq_setup_file` ещё раз (обновит токены/стили/генераторы) |
