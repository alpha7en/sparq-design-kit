## 00 · как пользоваться системой
- SPARQ · система карточек 1:1
- стиль: лёгкий красный неон + лёгкое стекло · формат: только квадрат 1080² (экспорт ×1.69 = 1824²)
- 1. Разметь пост: для каждого блока — роль (обложка / текст / данные / цитата / вывод / финал) и число слов.
- 2. Режим A (по умолчанию): карточка по таблице «какую карточку взять» (раздел 08) — инстанс из 04/05. Режим B: адаптируй инстанс под контент и фон (декор, шапка, тир заголовка). Режим C: нарисуй своё в стиле системы. Шаблоны — основа, не клетка.
- 3. Впиши тексты в свойства инстанса (title, text, counter, source…). Текст автора не переписывать; не влезает — kind=continue на следующей карточке, а не меньший кегль.
- 4. График: выбери форму по chart_selection.md, размер = слот карточки (XL/L/M/SW/SN). Типовые данные — свойство «график XX»; новые данные — генератор (sharedPluginData sparq/charts2) и вставка вместо слота.
- 5. Фон — под содержание, шапка — под фон: декор не заходит под рубрику/знак, текст, стекло и график. Ритм по разделу 08: ≤ 2 одинаковых фона подряд, 1–2 светлые, ≤ 1 красная.
- 6. Проверка: sparq.lint (sharedPluginData sparq/lint) — 0 замечаний; скриншот 1080 и ~390 px; карусель подряд.
- 7. Чего нет в системе — добавить вариант в компонент здесь же, с описанием, и строку в design/workbench/SYSTEM_MAP.md.
